# AutomationCodex

AutomationCodex is a Java Maven automation learning framework that contains both Selenium and Playwright implementations in a single project.

## Tech Stack

- Java 17
- Maven
- JUnit 5
- Selenium WebDriver
- Playwright Java
- Git and GitHub

## Framework Structure

```text
src/test/java/com/codex
├── selenium
│   ├── base
│   ├── factory
│   ├── pages
│   ├── tests
│   └── utils
└── playwright
    ├── base
    ├── factory
    ├── pages
    ├── tests
    └── utils


## Learning Goal

The goal of this project is to compare Selenium and Playwright side by side while building a company-style automation framework step by step.

This project also follows real-time Git and GitHub workflows such as feature branches, commits, pushes, pull requests, merges, and branch cleanup.
