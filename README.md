# AutomationCodex

AutomationCodex is a Java Maven automation learning framework that contains both Selenium and Playwright implementations in a single project.

## Tech Stack

- Java 17
- Maven
- JUnit 5
- Selenium WebDriver
- Playwright Java
- Git and GitHub

## Framework Structure

```text
src/test/java/com/codex
├── selenium
│   ├── base
│   ├── factory
│   ├── pages
│   ├── tests
│   └── utils
└── playwright
    ├── base
    ├── factory
    ├── pages
    ├── tests
    └── utils
